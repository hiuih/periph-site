      What these numbers can and can't tell you

      Update checks count downloads of manifest-win.json and manifest-mac.json. Each time periph checks for an update, it downloads the latest release's manifest. So these numbers show the app running somewhere. They don't count people.

      How often a copy checks depends on its version:

      • periph 1.0.1 checks at most about once a day, when the window opens.
      • 1.0.2 and later check every 10 minutes while running (including in the tray), and again when the window gets focus. One PC left on all day makes about 144 checks.
      • Copies with automatic checks turned off make no checks.
      • Pressing "Check for updates" adds one.

      Updates installed come from each version's tiny VERSION file. It changes in every release, so every in-app update downloads it exactly once. The count is exact per platform, except for retried or interrupted installs. If that file can't be identified, the card says it's an estimate.

      Bandwidth saved compares what updates actually downloaded (each update file's downloads × its size) with downloading the full installer for each of those installs.
