    04 · FAQ

    Quick answers.

    macOS says periph "can't be opened" or is from an unidentified developer.

    The Mac build isn't signed with an Apple developer certificate yet, so Gatekeeper blocks a plain double-click. Drag periph to Applications, then right-click it → Open, and confirm with Open. You only do this once.

    On newer macOS versions, if there's no Open button: try to open it once, then go to System Settings → Privacy & Security, scroll down and click Open Anyway.

    Why does macOS ask for Input Monitoring?

    macOS treats talking to a keyboard as input monitoring, even though periph only sends it settings. Allow it in System Settings → Privacy & Security → Input Monitoring, switch periph on, and reopen the app. Without it, the GK61 won't show up.

    Do I need to quit G HUB?

    Yes. G HUB holds on to the mouse and can overwrite the onboard profile with its own. Quit it from the tray icon (and stop it launching at startup) before you save from periph. Once your settings are on the mouse you can uninstall G HUB entirely. The same goes for the keyboard vendor's driver if it's running.

    Does periph have to stay open?

    No. Everything is written to the keyboard's and mouse's onboard memory. Close the app and your setup keeps working — on this computer or any other.

    Windows shows "Windows protected your PC".

    That's SmartScreen being cautious with a new, unsigned download. Click More info → Run anyway.

    Which devices does it support?

    Two, done properly: the 61-key Epomaker / Skyloong GK61 over USB, and the Logitech G305 through its LIGHTSPEED USB receiver. Other keyboards and mice aren't supported.

    Can I undo everything?

    The keyboard has a factory reset for both key layers built into the app. For the G305, periph saves a copy of the mouse's original onboard profile the first time it writes, and you can always set stages and buttons back by hand.
